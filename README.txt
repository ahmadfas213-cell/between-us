WEB PERMINTAAN MAAF

Isi:
- index.html
- style.css
- script.js
- assets/ (10 foto yang kamu kirim)

Cara pakai:
1. Buka index.html di browser.
2. Kalau mau pakai lagu, masukkan file audio yang kamu punya hak untuk digunakan ke:
   assets/sampai-jadi-debu.mp3
3. Klik tombol "putar musik".

Web ini dibuat tanpa framework, jadi tinggal dibuka atau di-upload ke GitHub Pages/hosting statis.
